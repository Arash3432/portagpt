# Portal AI

وب‌سایت، وب‌اپ گفتگو/تصویر و مرکز مدیریت آماده استقرار روی لیارا. این نسخه از Next.js 16، React 19، PostgreSQL، Redis، BullMQ و Object Storage خصوصی S3-compatible استفاده می‌کند.

## وضعیت نسخه ۱.۶

- رابط واکنش‌گرا برای موبایل و دسکتاپ با حرکت‌های کوتاه، بازخورد لمس/کلیک و حالت کاهش حرکت؛
- ورود و ثبت‌نام رمز-محور: ورود با موبایل+رمز، ثبت‌نام با موبایل+ایمیل+رمز+تکرار؛
- پیامک اختیاری با بازگشت خودکار به رمز؛
- کاتالوگ یکپارچه متن و تصویر، گروه‌بندی‌شده براساس شرکت؛
- اعتبار پیام سه‌ساعته و هفتگی، اعتبار تصویر مستقل و هفتگی؛
- تعداد اعتبار هر درخواست قابل تغییر از پنل مدیریت؛
- دفترکل اتمیک، رزرو/تسویه/بازپرداخت اعتبار و قطع‌کننده سراسری هزینه؛
- پنل مدیریت کاربران، پلن‌ها، مدل‌ها، ارائه‌دهنده، رخداد امنیتی و کنترل مالی؛
- کلید AI رمزگذاری‌شده با AES-256-GCM و URL ارائه‌دهنده قفل‌شده؛
- استقرار Docker روی لیارا و اجرای خودکار migration پیش از شروع.
- نشست پایدار و مشترک در همه صفحه‌ها: کاربر واردشده دوباره فرم ورود/ثبت‌نام نمی‌بیند و اختلال موقت نشست به‌صورت امن قابل‌تلاش‌مجدد است؛
- پنل مدیریت مقاوم در برابر پاسخ‌های دیررس جست‌وجو/Drawer و خطای موقت سرویس؛
- پنل مدیریت IP-only: فقط IPهای دقیق ثبت‌شده در `ADMIN_IP_ALLOWLIST` به `/admin` دسترسی دارند و سایر IPها 404 می‌گیرند؛
- cache خصوصی fail-closed، SSRF/redirect سخت‌گیرانه‌تر و گزارش/چک‌لیست انتشار ۱.۴.

## اتصال Liara AI

Base URL و allowlist آن فقط از متغیرهای سمت‌سرور Liara خوانده می‌شوند:

```text
AI_BASE_URL=https://ai.liara.ir/api/6a8891dfffbd76a99cabcca4/v1
AI_PROVIDER_HOST_ALLOWLIST=ai.liara.ir
```

کلید را پس از بازشدن IP-only پنل در `/admin` و بخش «اتصال Liara AI» وارد کنید. کلید در پاسخ API یا رابط برگردانده نمی‌شود و فقط چهار رقم آخر برای تشخیص نمایش داده می‌شود.

قیمت‌های کاتالوگ تخمین محافظه‌کارانه‌اند، چون قیمت قطعی مدل‌های جدید ممکن است با صورتحساب حساب شما فرق کند. پیش از فروش واقعی، قیمت هر مدل و ضریب اطمینان را با صورتحساب Liara AI هماهنگ کنید.

## اجرای محلی

پیش‌نیاز: Node.js 22.13 یا جدیدتر، PostgreSQL و Redis.

```bash
npm ci
node --env-file=.env.local scripts/migrate.mjs
npm run dev
```

متغیرهای لازم را با الگوی `.env.example` در فایل خصوصی `.env.local` تنظیم کنید؛ برای توسعه `NODE_ENV=development` و origin محلی قرار دهید. در استقرار فقط از Environment میزبان استفاده کنید. فایل `.env` واقعی نباید بسته‌بندی یا commit شود.

## استقرار روی لیارا

1. برنامه Docker، PostgreSQL، Redis و Object Storage خصوصی بسازید.
2. اتصال‌ها و Secretهای `.env.example` را در Environment برنامه قرار دهید.
3. Secretها را با `npm run secrets:generate` یا `GENERATE-SECRETS.html` آفلاین بسازید.
4. `PUBLIC_APP_URL` و `ADMIN_IP_ALLOWLIST` را فقط در Secrets لیارا تنظیم کنید. برای پنل IP-only، allowlist نباید خالی باشد.
5. Deploy کنید. فرمان شروع ابتدا تنظیمات را بررسی، سپس migrationها را اجرا و خروجی standalone آماده‌شده Next.js را روی `0.0.0.0:3000` باز می‌کند. IP مجاز مستقیماً `/admin` را باز می‌کند و IP غیرمجاز 404 می‌گیرد.
6. `/api/health`، سپس `/admin` و تست Liara AI را بررسی کنید.

برای راه‌اندازی `START-HERE.md`، راهنمای کامل انتشار `LIARA-DEPLOYMENT.md` و برای کار با مدیر `ADMIN-GUIDE.md` را بخوانید.

## امنیت و کنترل هزینه

- نشست‌های عادی دارای کوکی HttpOnly/Secure/SameSite و CSRF هستند؛
- پنل مدیریت بدون نشست و رمز، با allowlist غیرخالی و دقیق IP و بررسی مبدأ درخواست محافظت می‌شود؛
- IP غیرمجاز هم در صفحه و هم در APIهای مدیریت پاسخ 404 می‌گیرد؛
- محدودسازی نرخ در Redis و تعلیق خودکار رفتار پرخطر فعال است؛
- کاتالوگ و Base URL در سرور اعتبارسنجی و خروجی تصاویر در برابر SSRF بررسی می‌شود؛
- رزرو هزینه و اعتبار با advisory lock و تراکنش اتمیک انجام می‌شود؛
- درخواست شکست‌خورده بدون خروجی، اعتبار کاربر را آزاد می‌کند؛
- سقف هزینه روزانه کل مستقل از اعتبار کاربران است و جلوی خرج خارج از کنترل را می‌گیرد؛
- پرداخت به‌صورت Fail-closed و پیش‌فرض خاموش است.

همه افراد پشت IP مجاز، دسترسی مدیر دارند؛ خروجی VPN عمومی یا NAT مشترک مناسب این حالت نیست. اگر IP ثابت اختصاصی ندارید، IP-only برای شما مناسب نیست؛ از مسیر اختصاصی و کنترل‌شده استفاده کنید. حذف یا خالی‌کردن `ADMIN_IP_ALLOWLIST` عمداً دسترسی `/admin` را برای همه می‌بندد.

جزئیات واکنش به رخداد در `SECURITY.md` است.

## فرمان‌های بررسی

```bash
npm test
npm run build
npm run validate:artifact
```

`npm test` تست‌های امنیت، دارایی‌ها، متن/استریم، شروع و migration، TypeScript و lint را اجرا می‌کند. `validate:artifact` خروجی standalone، تطابق migrationهای کامپایل‌شده، نسخه بسته و تنظیمات Liara را بررسی می‌کند. `LIARA-PREDEPLOY-CHECKLIST.md` چک‌لیست جاری است؛ فایل‌های گزارش شماره‌دار قدیمی فقط تاریخچه همان نسخه‌اند.
